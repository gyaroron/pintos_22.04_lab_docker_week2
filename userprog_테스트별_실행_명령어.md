# userprog 테스트별 실행 명령어

작성일: 2026-10-16 (KST). 등록 66종 = 기본 64종 + 선택 dup2 2종. 명령 안내이며 빌드·테스트는 미실행이다.

Linux DevContainer의 Bash에서 저장소 내부 터미널을 열고 사용한다. 현재 README의 개발 환경을 먼저 준비한다.

```bash
cd "$(git rev-parse --show-toplevel)/pintos/userprog"
```

기본 선택 실행은 `make -B check TESTS=...`이다. 결과는 `build/<테스트 키>.result`, 출력은 `.output`, 표준 오류는 `.errors`에서 확인한다. 공식 `.result`가 PASS인지 확인하며 프로그램의 종료 코드가 0인지 여부만으로 판단하지 않는다.

Make.tests에 등록된 fixture와 보조 프로그램은 공식 하네스가 전달한다. `.errors`가 비어 있어야 한다는 추가 판정 조건을 만들지 않는다. 기본 전체 make check에는 filesys/base·threads도 포함되므로 userprog 64종 선택 실행과 구분한다.

## 선택 dup2와 장시간 케이스

dup2 두 명령은 TEST_SUBDIRS와 TDEFINE를 명령줄에서 지정해 해당 실행에만 추가 범위를 포함한다. 기본 Make.vars는 수정하지 않는다. 선택 2종은 기본 64종 통과와 별도로 기록한다.

multi-oom은 등록 설정의 TIMEOUT=600 및 -m 20을 존중한다. 사용자 명령에서 임의로 기본 60초로 줄이지 않는다.
