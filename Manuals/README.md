기본 Project 자동화는 PR #161 병합 후 활성화했습니다. **Todo로 옮길 때 담당을 모두 해제하는 추가 정책은 별도 PR의 승인·main 병합 후 적용됩니다.** 문서 추가만으로 적용된 것은 아닙니다. 나머지 세 상태는 최근 이동자 단독 담당, 전체 자식 Done은 부모 Closed+Done 정책을 유지합니다. 리뷰어는 자동 배정하지 않습니다.

작업할 하위 이슈를 선택한 다음 로컬 작업 매뉴얼과 테스트별 실행 명령을 함께 확인하세요. 실제 실행 명령·코드 버전·결과는 작업 PR에 기록합니다.
